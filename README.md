# PS Link Checker

**Funktionierende Links sind keine Nebensache.** Der **PS Link Checker** überwacht Deine Website automatisch auf defekte Links, fehlende Bilder und Weiterleitungen – und hilft Dir dabei, Deine Inhalte sauber und aktuell zu halten.

PS Link Checker ist eine für **ClassicPress weiterentwickelte und gepflegte Version des beliebten Broken Link Checkers**.

Dabei bleibt das Plugin nicht auf ClassicPress beschränkt: **PS Link Checker funktioniert auch mit WordPress** und kann dort ebenfalls zur automatischen Linkprüfung eingesetzt werden.

> 💡 **Aus der Community:** Einige Nutzer berichten, dass PS Link Checker bei ihnen stabiler bzw. fehlerfreier läuft als frühere Versionen des ursprünglichen Plugins.

## Warum PS Link Checker?

Im Laufe der Zeit sammeln sich auf jeder Website Links an. Webseiten verschwinden, URLs ändern sich, Bilder werden gelöscht und externe Seiten werden umstrukturiert.

PS Link Checker übernimmt die Kontrolle und sucht automatisch nach Problemen in Deinen Inhalten.

### Das kann PS Link Checker

* 🔎 Überwacht Links in **Beiträgen, Seiten und Kommentaren**
* 🔗 Unterstützt die **Blogroll** und benutzerdefinierte Felder
* ❌ Erkennt **defekte Links**
* 🖼️ Erkennt **fehlende oder nicht erreichbare Bilder**
* ↪️ Erkennt **Weiterleitungen**
* 📊 Zeigt den aktuellen Status Deiner Links übersichtlich im Backend
* 📧 Benachrichtigt Dich optional **per E-Mail**
* 🔔 Informiert Dich über das **Dashboard**
* ✏️ Ermöglicht die Bearbeitung von Links direkt über die Plugin-Oberfläche
* 🔍 Sucht und filtert Links nach **URL, Ankertext, Status** und weiteren Kriterien
* 🎯 Unterstützt individuelle Linkfilter
* ⚙️ Bietet umfangreiche Konfigurationsmöglichkeiten
* 🚫 Kann verhindern, dass Suchmaschinen **defekten Links folgen**
* 🎨 Kann defekte Links in Deinen Inhalten **optisch kennzeichnen**

## Für ClassicPress und WordPress

PS Link Checker wurde mit einem klaren Fokus auf **ClassicPress** weiterentwickelt und modernisiert.

Gleichzeitig bleibt das Plugin mit **WordPress** kompatibel.

Damit eignet es sich sowohl für klassische WordPress-Projekte als auch für moderne ClassicPress-Websites.

## Grundlegende Verwendung

Nach der Installation beginnt PS Link Checker damit, Deine Inhalte nach Links zu durchsuchen.

Dabei können unter anderem folgende Bereiche berücksichtigt werden:

* Beiträge
* Seiten
* Kommentare
* Blogroll / Lesezeichen
* Benutzerdefinierte Felder

Je nach Größe Deiner Website und der Anzahl vorhandener Inhalte kann die erste Analyse einige Minuten bis hin zu einer Stunde oder länger dauern.

Anschließend überprüft PS Link Checker die gefundenen Links und ermittelt, ob sie funktionieren, weiterleiten oder nicht mehr erreichbar sind.

Den Fortschritt und die Einstellungen für die Linkprüfung findest Du unter:

**Einstellungen → Link Checker**

## Defekte Links verwalten

Gefundene Probleme werden übersichtlich unter

**Werkzeuge → Defekte Links**

angezeigt.

Zusätzlich informiert Dich das Dashboard-Widget **„Defekte Links“** über erkannte Probleme.

Das Widget kann geschlossen bleiben, um Platz im Dashboard zu sparen, und so konfiguriert werden, dass es sich automatisch öffnet, sobald problematische Links gefunden wurden.

### E-Mail-Benachrichtigungen

Auf Wunsch kann PS Link Checker Dich zusätzlich per E-Mail über erkannte Probleme informieren.

Die E-Mail-Benachrichtigungen lassen sich separat unter

**Einstellungen → Link Checker**

aktivieren.

## Nicht nur defekte Links

Die Übersicht beschränkt sich nicht ausschließlich auf kaputte URLs.

Du kannst zwischen verschiedenen Linkzuständen wechseln und Dir beispielsweise anzeigen lassen:

* defekte Links
* Weiterleitungen
* funktionierende Links
* alle gefundenen Links

Über die Suchfunktion kannst Du die Ergebnisse zusätzlich eingrenzen.

### Eigene Filter erstellen

Du kannst aus Deinen Suchergebnissen einen **benutzerdefinierten Filter** erstellen.

So kannst Du beispielsweise einen Filter anlegen, der ausschließlich Links aus Kommentaren anzeigt.

Damit lassen sich auch große Websites gezielt untersuchen, ohne sich durch eine endlose Liste arbeiten zu müssen.

## Links direkt bearbeiten

Einer der größten Vorteile von PS Link Checker:

**Du musst nicht jeden Beitrag einzeln öffnen, um einen defekten Link zu korrigieren.**

Bewege den Mauszeiger über einen gefundenen Link, um die verfügbaren Aktionen anzuzeigen.

### URL bearbeiten

Mit **„URL bearbeiten“** kannst Du die Zieladresse eines Links direkt ändern.

Befindet sich dieselbe URL an mehreren Stellen – beispielsweise sowohl in einem Beitrag als auch in der Blogroll – können alle Vorkommen dieser URL gleichzeitig aktualisiert werden.

### Verknüpfung aufheben

Mit **„Verknüpfung aufheben“** entfernst Du den Link, während der vorhandene Linktext erhalten bleibt.

### Nicht defekt

Nicht jeder vermeintlich defekte Link ist tatsächlich kaputt.

Ein Netzwerkfehler oder ein vorübergehendes Problem kann dazu führen, dass ein funktionierender Link fälschlicherweise als defekt erkannt wird.

Mit **„Nicht defekt“** kannst Du einen solchen Link manuell als funktionierend markieren.

PS Link Checker überprüft ihn weiterhin regelmäßig. Erst wenn sich sein tatsächlicher Status entsprechend ändert, wird er wieder als problematisch behandelt.

### Verwerfen

Mit **„Verwerfen“** kannst Du einen Link aus den Ansichten **„Defekte Links“** und **„Weiterleitungen“** ausblenden.

Der Link wird weiterhin regulär geprüft und erhält auch weiterhin die entsprechenden Linkstile.

Er wird jedoch erst wieder in den entsprechenden Ansichten angezeigt, wenn sich sein Status verändert.

Ideal für Links, deren Status Du bereits überprüft hast und die Du bewusst so belassen möchtest.

## Detaillierte Statusinformationen

Klicke in der Übersicht auf den Inhalt der Spalten **„Status“** oder **„Linktext“**, um zusätzliche Informationen zum jeweiligen Link aufzurufen.

So kannst Du schnell nachvollziehen, warum ein Link als problematisch erkannt wurde.

## Für kleine und große Websites

Ob persönliche Website, Blog, Community oder umfangreiches Content-Projekt:

PS Link Checker hilft Dir dabei, Deine Links im Blick zu behalten.

Gerade bei großen Websites können sich über die Jahre tausende Links ansammeln. Eine manuelle Kontrolle ist dann praktisch unmöglich.

PS Link Checker übernimmt diese Arbeit automatisch.
